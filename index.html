Privacy Policy

อัปเดตล่าสุด: พฤษภาคม 2026

Patta.me เชื่อในความโปร่งใส เราจะบอกตรงๆ ว่าเก็บข้อมูลอะไร ไม่เก็บอะไร และทำไม

1. ข้อมูลที่เราเก็บ

เราเก็บข้อมูลเท่าที่จำเป็นเท่านั้น แบ่งออกเป็น 2 ส่วน

✅ ข้อมูลที่ user กรอกเอง (เช่น ใน Jodyub)

  • ชื่อทริป วันที่ จุดหมาย
  • รายการค่าใช้จ่าย และสกุลเงิน
  • ชื่อผู้เดินทาง (กรอกเองโดยไม่ต้องยืนยัน identity)

✅ ข้อมูลจาก Feedback Form

  • อีเมล (ถ้ากรอก — ไม่บังคับ)
  • ข้อความ feedback ที่ส่งมา

2. ข้อมูลที่เราไม่เก็บ

  • ❌ ไม่เก็บรหัสผ่าน — ไม่มีระบบ login
  • ❌ ไม่เก็บข้อมูลบัตรเครดิต หรือข้อมูลการเงินส่วนตัว
  • ❌ ไม่ติดตาม behavior ด้วย tracking pixel
  • ❌ ไม่มีโฆษณา และไม่ขายข้อมูลให้ third party
  • ❌ ไม่เก็บ IP address หรือข้อมูล device โดยตรง

3. เราเก็บข้อมูลไว้ที่ไหน

ข้อมูลของ Jodyub ถูกเก็บบน Firebase Realtime Database ของ Google ซึ่งอยู่ใน Server เขต United States ข้อมูล Feedback Form ถูกส่งผ่าน Web3Forms ไปยังอีเมลของทีมงาน

4. Trip Code และความเป็นส่วนตัว

ข้อมูลในแต่ละทริปถูกแยกด้วย Trip Code — ใครที่มี code นั้นถึงจะเข้าถึงข้อมูลได้ เราแนะนำให้แชร์ Trip Code เฉพาะกับคนในทริปเท่านั้น

5. Cookies

Patta.me ใช้ localStorage ของ browser เพื่อจำทริปล่าสุดที่เคยเข้าใช้งาน ไม่มีการใช้ tracking cookies หรือ third-party cookies

6. สิทธิ์ของคุณ

คุณมีสิทธิ์ขอให้ลบข้อมูลทริปของคุณออกจากระบบได้ทุกเมื่อ โดยติดต่อเราที่

📧 taionthego.co@gmail.com

7. การเปลี่ยนแปลง Privacy Policy

หาก Privacy Policy มีการเปลี่ยนแปลง เราจะอัปเดตวันที่ด้านบนและแจ้งให้ทราบผ่านหน้าเว็บ
